# 06 · 数据库与缓存

> 源码：`system/core/database.py`、`system/core/get_db.py`、`system/core/get_redis.py`、`system/core/env.py`

## 一、ORM 选型

| 项 | 选型 |
| -- | ---- |
| ORM | SQLAlchemy 2.x + AsyncAttrs + declarative |
| 异步驱动（MySQL） | `asyncmy` |
| 异步驱动（PostgreSQL） | `asyncpg` |
| 同步驱动（定时任务 JobStore） | `pymysql` / `psycopg2-binary` |
| 会话管理 | `async_sessionmaker(autocommit=False, autoflush=False)` |
| 数据库创建 | `Base.metadata.create_all`（启动自动建表） |

## 二、数据库连接配置

```python
# system/core/env.py
class DataBaseSettings(BaseSettings):
    db_type: Literal['mysql', 'postgresql'] = 'mysql'
    db_host: str = '192.168.40.32'
    db_port: int = 3307
    db_username: str = 'root'
    db_password: str = 'welcome123!'
    db_database: str = 'xeapp'
    db_echo: bool = True
    db_max_overflow: int = 10
    db_pool_size: int = 50
    db_pool_recycle: int = 3600
    db_pool_timeout: int = 30
```

`.env` 支持主从库分离字段（`DB_MASTER_*` / `DB_SLAVE_*`），可用于读写分离。

## 三、Engine & Session

```python
# system/core/database.py
ASYNC_SQLALCHEMY_DATABASE_URL = f'mysql+asyncmy://{user}:{pwd}@{host}:{port}/{db}'
async_engine = create_async_engine(URL, echo=True, pool_size=10, pool_recycle=3600)
AsyncSessionLocal = async_sessionmaker(autocommit=False, autoflush=False, bind=async_engine)

class Base(AsyncAttrs, DeclarativeBase):
    pass
```

**依赖注入**（用于 Controller）：

```python
# system/core/get_db.py
async def get_db():
    async with AsyncSessionLocal() as current_db:
        yield current_db
```

Controller 中使用：

```python
@router.get("/list")
async def user_list(db: AsyncSession = Depends(get_db)):
    ...
```

## 四、数据表命名规范

| 规则 | 示例 |
| ---- | ---- |
| 表名前缀 | `sys_` |
| 表名格式 | `sys_{module}_{entity}` 如 `sys_production_plan` |
| 主键 | `{entity}_id`（整型自增或 UUID） |
| 时间字段 | `create_time` / `update_time`（DateTime） |
| 创建人/修改人 | `create_user` / `update_user` |
| 逻辑删除 | `is_delete`（Boolean，默认 0） |

## 五、ORM Model 示例

```python
# product/models/product.py
from core.database import Base
from sqlalchemy import Column, Integer, String, DateTime, Boolean, Text, Numeric
from datetime import datetime

class SysProduct(Base):
    __tablename__ = "sys_product"
    product_id = Column(Integer, primary_key=True, autoincrement=True)
    product_name = Column(String(200), nullable=False, comment="商品名称")
    category_id = Column(Integer, comment="分类ID")
    brand_id = Column(Integer, comment="品牌ID")
    unit_id = Column(Integer, comment="单位ID")
    price = Column(Numeric(10, 2), comment="单价")
    is_delete = Column(Boolean, default=False)
    create_time = Column(DateTime, default=datetime.now)
    update_time = Column(DateTime, default=datetime.now, onupdate=datetime.now)
```

## 六、Redis 使用

### 6.1 连接池（`system/core/get_redis.py`）

```python
redis = await aioredis.from_url(
    url=f'redis://{redis_host}',
    port=redis_port,
    username=redis_username,
    password=redis_password,
    db=redis_database,
    encoding='utf-8',
    decode_responses=True,
)
app.state.redis = redis
```

各 Controller / Service 通过 `request.app.state.redis` 访问。

### 6.2 启动缓存预热

| 预热方法 | 用途 |
| -------- | ---- |
| `init_sys_dict` | 字典数据序列化到 Redis |
| `init_sys_config` | 系统参数序列化到 Redis |
| `init_sys_user` | 用户基础信息序列化到 Redis |

### 6.3 常见 Key 分布

| Key 模式 | 用途 |
| -------- | ---- |
| `ACCESS_TOKEN:{session_id}` | 在线会话 |
| `CAPTCHA_CODE:{uuid}` | 登录验证码 |
| `PASSWORD_ERROR_COUNT:{username}` | 密码错误计数 |
| `ACCOUNT_LOCK:{username}` | 账号锁定标记 |
| `sys_dict:{dict_type}` | 字典缓存 |
| `sys_config:{config_key}` | 参数缓存 |

## 七、事务管理

默认无自动 commit，由 Service 层手动：

```python
async def add_user(self, db: AsyncSession, user_model):
    db.add(user_model)
    await db.commit()
    await db.refresh(user_model)
```

需要跨表原子操作时：

```python
async with db.begin():
    db.add(order)
    db.add(order_item)
# begin() 退出时自动 commit，异常自动 rollback
```

## 八、注意事项

1. `pool_recycle=3600`：MySQL wait_timeout 默认 28800s，确保连接池回收时间小于服务端超时。
2. `db_echo=True`：开发环境方便调试，生产**务必关闭**，否则日志暴涨。
3. 同步 engine 共存：`get_scheduler.py` 需要同步 `SessionLocal`（APScheduler 内部不支持 async），因此项目中维护了一个额外的同步 engine。
4. 主从部署时将读请求走 `DB_SLAVE` engine，写走 `DB_MASTER`。当前代码尚未拆分，但 `.env` 已预留字段。
