# 12 · 开发指南

本章面向**新加入的开发人员**，快速掌握如何在 XEERP-FASTAPI 中新增接口、新增服务、编写规范代码。

---

## 一、新增接口（在已有服务中）

以在 `product` 服务新增"商品批量导入"接口为例。

### Step 1：定义 Schema（请求/响应模型）

```python
# product/schemas/product_schema.py
class ProductImportModel(BaseModel):
    file_url: str
    overwrite: bool = False
```

### Step 2：编写 Service

```python
# product/service/product_service.py
class ProductService:
    @classmethod
    async def batch_import(cls, db: AsyncSession, params: ProductImportModel):
        # 业务逻辑...
        return CrudResponseModel(is_success=True, message="导入成功")
```

### Step 3：编写 DAO（如需自定义 SQL）

```python
# product/dao/product_dao.py
class ProductDao:
    @classmethod
    async def batch_insert(cls, db: AsyncSession, products: list):
        db.add_all(products)
        await db.flush()
```

### Step 4：编写 Controller

```python
# product/api/v1/product_controller.py
@productController.post("/import")
async def import_products(file: UploadFile, db: AsyncSession = Depends(get_db)):
    result = await ProductService.batch_import(db, file)
    return ResponseUtil.success(data=result)
```

### Step 5：验证

启动服务后访问 `http://localhost:8002/api/docs`，找到新接口调试。

## 二、新增微服务

以新建 `finance`（财务）服务为例。

### Step 1：创建目录

```bash
mkdir finance
cd finance
mkdir core api api/v1 models schemas service dao clients middlewares
```

### Step 2：复制骨架文件

从 `product` 或 `system` 复制：
- `run.py` — 修改端口
- `server.py` — 修改 app_name
- `core/env.py` — 修改 `app_port`
- `core/database.py`、`core/get_db.py` — 原样复制
- `api/__init__.py` — 空的路由注册函数
- `middlewares/handle.py` — 中间件注册

### Step 3：配置端口

在 `core/env.py` 中设置 `app_port: int = 8010`。

### Step 4：注册到网关

在 `gateway/core/env.py` 增加：
```python
finance_service_url: str = "http://127.0.0.1:8010"
```

在 `gateway/router/gateway_router.py` 增加路由前缀：
```python
"/api/finance": AppConfig.finance_service_url,
"/finance": AppConfig.finance_service_url,
```

### Step 5：启动验证

```bash
cd finance && python run.py
```

## 三、代码规范

### 3.1 命名规范

| 类型 | 规范 | 示例 |
| ---- | ---- | ---- |
| 文件名 | snake_case | `product_service.py` |
| 类名 | PascalCase | `ProductService` |
| 函数/方法 | snake_case | `get_product_list` |
| 常量 | UPPER_SNAKE | `MAX_PAGE_SIZE` |
| 数据表 | `sys_{module}_{entity}` | `sys_product_category` |
| API 路由 | kebab-case 或 camelCase | `/api/product/list` |

### 3.2 分层约束

| 层 | 允许调用 | 禁止 |
| -- | -------- | ---- |
| Controller | Service | 直接访问 DAO/Model |
| Service | DAO / Client / Redis | 直接返回 JSONResponse |
| DAO | Model | 耦合 HTTP 对象 |
| Client | 外部 HTTP | 在 Controller 直接调用 |

### 3.3 异常处理

- 业务异常统一使用 `ServiceException` / `LoginException` 等
- 不要在 Controller 中 try/catch 后吞掉异常——让全局 handler 统一处理
- 需要返回 "可预期失败" 用 `ResponseUtil.failure(msg=...)`

### 3.4 日志规范

```python
from utils.log_util import setup_logger
logger = setup_logger("finance")

logger.info("创建财务记录: %s", record_id)
logger.warning("余额不足: user=%s, amount=%s", user_id, amount)
logger.error("数据库异常", exc_info=True)
```

## 四、数据库变更

- 新增表：在服务 `models/` 中创建 Model，启动时自动建表
- 字段变更：当前无 migration 工具——建议引入 `alembic`
  ```bash
  alembic init migrations
  alembic revision --autogenerate -m "add finance tables"
  alembic upgrade head
  ```
- 种子数据：放在 `script_task/` 或手动 SQL 脚本

## 五、跨服务调用

使用 `httpx.AsyncClient` 封装到 `clients/` 目录：

```python
# finance/clients/stock_client.py
from clients.base_client import BaseClient

class StockClient(BaseClient):
    SERVICE_URL = "http://127.0.0.1:8003"

    @classmethod
    async def get_inventory(cls, product_id: int):
        return await cls.get(f"/api/stock/inventory/{product_id}")
```

`BaseClient` 封装超时、重试、异常转换。

## 七、部署 Checklist

- [ ] `.env` 中 `APP_RELOAD=false`、`DB_MASTER_ECHO=false`
- [ ] 配置 `gunicorn` 多 worker（参考 `system/gunicorn_conf.py`）
- [ ] Nginx 反向代理 Gateway（TLS、静态资源、日志）
- [ ] 每个服务注册为 systemd unit
- [ ] 监控：Prometheus + Grafana（建议接入 `starlette-exporter`）
- [ ] 日志收集：ELK / Loki
- [ ] Redis 高可用（Sentinel / Cluster）
- [ ] MySQL 主从同步

## 八、常见踩坑

| 问题 | 原因 | 解决 |
| ---- | ---- | ---- |
| `ImportError: No module named 'utils'` | 没有从服务目录内启动 | `cd {service} && python run.py` |
| `RuntimeError: no running event loop` | 在同步代码中调用 async | 确认使用 `await` 或改用同步 API |
| 数据库连接耗尽 | `pool_size` 过小或未关闭 session | 增大 pool_size，确保 `yield` 后释放 |
| Redis key 冲突 | 多服务共用 DB 编号 | 不同服务使用不同 `redis_database` |
| 定时任务不执行 | `invoke_target` 路径错误 | 确保 `script_task/` 已被 import |
