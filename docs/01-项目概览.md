# 01 · 项目概览

> 适用版本：v1.0  · 最近更新：2026-05

## 一、项目定位

**XEERP-FASTAPI** 是一套基于 **FastAPI + SQLAlchemy + MySQL + Redis** 构建的**企业级进销存（ERP）微服务系统**，面向中小制造与流通型企业，覆盖系统权限、商品、库存、生产、采购、销售、报表、审批等业务领域。

整体采用**分层模块化微服务架构**：
- 单一职责：每个服务专注一个业务领域
- 进程隔离：每个服务独立进程、独立端口、可独立部署与扩缩容
- 接入统一：所有外部流量经 **Gateway** 网关收敛，再按路径前缀转发到下游服务
- 共享内核：核心通用工具（`utils/`、`web-ui/`、共享 `.env`）保留在项目根目录共用

---

## 二、核心价值

| 价值点 | 说明 |
| ------ | ---- |
| 服务边界清晰 | 10 个微服务严格按业务域拆分，便于多人协作与领域演进 |
| 统一技术栈 | 全部服务统一使用 FastAPI + SQLAlchemy 2.x 异步 ORM，新人上手成本低 |
| 异步高并发 | 全链路 `async/await`，数据库使用 `asyncmy`，Redis 使用 `aioredis` |
| 网关统一接入 | 鉴权、限流、日志、CORS 都集中在 Gateway，业务服务无需重复实现 |
| 缓存预热 | 字典、参数、用户信息启动时预加载 Redis，热点接口纳秒级响应 |
| 调度可治理 | 集成 APScheduler，定时任务可在线增删改查，支持 Cron 表达式与日志追踪 |
| 前后端解耦 | 后端纯 REST，前端独立 `web-ui`（Vue3 + Vite + Element Plus） |

## 四、技术栈

| 分层 | 选型 | 版本要求 | 用途 |
| ---- | ---- | -------- | ---- |
| 编程语言 | Python | 3.12+ | 全栈语言 |
| Web 框架 | `fastapi` `uvicorn` `gunicorn` `httptools` | latest | 异步 HTTP 服务、生产部署 |
| 序列化 | `orjson` | latest | 高性能 JSON 序列化（替换默认 json） |
| ORM | `sqlalchemy` 2.x | 2.0+ | 异步 ORM、声明式建模 |
| 数据库驱动 | `asyncmy`（MySQL） `psycopg2-binary`（PG）`pymysql` | latest | 异步/同步 DB 驱动并存 |
| 缓存中间件 | `redis`（含 `redis.asyncio`） | 5.0+ | 会话、字典/参数缓存、限流 |
| 鉴权 | `pyjwt` `passlib`（bcrypt） | latest | JWT 签发校验、密码哈希 |
| 配置管理 | `python-dotenv` `pydantic-settings` | latest | `.env` 配置加载、类型校验 |
| 日志 | `loguru`（utils）+ `logging`（部分服务） | latest | 控制台 + 文件按天轮转 + zip 归档 |
| 限流 | `slowapi` + Redis | latest | 网关侧 IP 速率限制 |
| 定时调度 | `apscheduler` | latest | Cron 任务、SQLAlchemy/Redis JobStore |
| 反向代理（生产） | Nginx | - | TLS、静态、反向代理网关 |
| 前端 | Vue3 + Vite + Element Plus（基于 RuoYi-Vue3 二次开发） | - | 管理后台 |

详见根目录 [requirements.txt](../requirements.txt)。

## 五、服务清单与端口

| 服务 | 端口 | 是否提供 `core/get_db.py` | 是否调用上游 | 主要数据表前缀 |
| ---- | ---- | ------------------------- | ------------ | -------------- |
| gateway | 8000 | ❌（无 DB） | 所有下游 | - |
| system | 8001 | ✅ | - | `sys_*` |
| product | 8002 | ✅ | system | `sys_product*` |
| stock | 8003 | ✅ | system | `sys_warehouse / sys_inventory*` |
| production | 8004 | ✅ | system / stock | `sys_bom*`、`sys_production*` |
| report | 8005 | ✅ | production / stock | 跨服务聚合 |
| approval | 8006 | ✅ | system | `sys_approval*` |
| partner | 8007 | ✅ | system | `sys_partner*` |
| order | 8008 | ✅ | partner / product | `sys_order*` |
| purchase | 8009 | ✅ | partner / product / stock | `sys_purchase*` |

> 注：当前部分服务已实现完整业务，部分服务（`purchase`、`approval`）只是占位骨架（仅 `main.py`），需要根据 [12-开发指南](./12-开发指南.md) 按既有规范扩展。
