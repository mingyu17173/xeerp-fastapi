# 二、直接给你最终版 `gunicorn_conf.py`

```python
# Gunicorn + Uvicorn 生产配置（自动重启 + 防卡死 + 高性能）
import multiprocessing

bind = "0.0.0.0:8000"
workers = multiprocessing.cpu_count() * 2
worker_class = "uvicorn.workers.UvicornWorker"

# ====================== 【自动重启、防卡死】核心配置 ======================

# 1. 自动重启：每个 worker 处理 50000 请求后自动重启（防内存泄漏）
max_requests = 50000
max_requests_jitter = 1000  # 随机抖动，避免所有进程同时重启

# 2. 防卡死：30 秒没响应自动重启
timeout = 30

# 3. 平滑重启，不给业务报错
graceful_timeout = 30

# 4. 长连接
keepalive = 5

# ======================================================================

# 性能
worker_connections = 2000
loglevel = "warning"
accesslog = None
errorlog = "-"
proc_name = "erp_micro"
```

# 三、这 3 个参数到底怎么防卡死、自动重启？
## 1. `max_requests = 50000`
- 每个 worker 处理 **5万请求** 后**自动优雅重启**
- 彻底解决：**内存泄漏、句柄泄漏、长期运行变慢**

## 2. `timeout = 30`
- 如果 worker **30秒不响应**（卡死、死锁、死循环）
- Gunicorn **直接杀死并重启这个 worker**
- 业务几乎无感知

## 3. `graceful_timeout = 30`
- 重启时**等请求处理完再关闭**
- **不会断连接、不会报错**

# 四、这还不够安全？再加 2 层保险（Linux 生产必备）
## 保险 1：systemd 自动拉起（服务挂了立刻重启）
创建 `/etc/systemd/system/erp-gateway.service`
```ini
[Unit]
Description=ERP Gateway Service
After=network.target

[Service]
User=root
WorkingDirectory=/app/gateway-service
ExecStart=/usr/bin/gunicorn main:app -c gunicorn_conf.py
Restart=always        # 挂了自动重启
RestartSec=3
LimitNOFILE=65535

[Install]
WantedBy=multi-user.target
```

启动：
```bash
systemctl daemon-reload
systemctl enable erp-gateway
systemctl start erp-gateway
```

## 保险 2：健康检查 + 自动恢复（脚本）
`auto-restart.sh`
```bash
#!/bin/bash
check() {
    port=$1
    name=$2
    if ! lsof -i TCP:$port | grep LISTEN >/dev/null 2>&1; then
        echo "🚨 $name 挂了，自动重启..."
        cd /app/$name && nohup gunicorn main:app -c gunicorn_conf.py >> ../logs/restart.log 2>&1 &
    fi
}

check 8000 gateway-service
check 8001 system-service
check 8002 product-service
check 8003 stock-service
check 8004 production-service
check 8005 report-service
check 8006 approval-service
check 8007 partner-service
```

加入定时任务 **每分钟检查一次**：
```bash
* * * * * /app/auto-restart.sh
```
