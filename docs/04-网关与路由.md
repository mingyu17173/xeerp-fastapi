# 04 · 网关与路由

> 源码：[`gateway/`](../gateway/)

Gateway 是 XEERP-FASTAPI 的**唯一外部入口**，承担四大职责：路由转发、JWT 鉴权、IP 限流、日志记录。


```python
class AppConfig(BaseSettings):
```

> 当前 `service_routes` 只显式登记了 system / product / stock / production / report；如需把 `approval / partner / order / purchase` 暴露给外部，需要：
> 1. 在 `env.py` 增加 `approval_service_url` 等字段；
> 2. 在 `gateway_router.py` 的 `service_routes` 字典补全前缀映射。

## 四、转发实现

```python
@router.api_route("/{path:path}", methods=["GET","POST","PUT","DELETE","PATCH","OPTIONS"])
@limiter.limit(f"{rate_limit_requests}/{rate_limit_window_seconds}seconds")
async def proxy_request(request: Request, path: str):
    target_service = await get_target_service(f"/{path}")
    if not target_service:
        raise HTTPException(status_code=404, detail="未找到对应的服务")
    url = f"{target_service}/{path}"
    headers = {k: v for k, v in request.headers.items() if k != "host"}
    async with httpx.AsyncClient() as client:
        response = await client.request(
            method=request.method,
            url=url,
            headers=headers,
            content=await request.body(),
            timeout=30,
        )
        return httpx.Response(
            status_code=response.status_code,
            headers=dict(response.headers),
            content=response.content,
        )
```

要点：
- **Host 头剥离**：避免 httpx 报错 `Invalid host header`
- **Body 透传**：使用 `await request.body()` 原样转发，兼容 form/json/multipart
- **超时 30 秒**：长任务接口请走异步任务化，不要直接在网关同步等待
- **未匹配**：返回 404 "未找到对应的服务"
- **下游不可达**：返回 503 "服务不可用"

## 五、中间件链路（[`gateway/server.py`](../gateway/server.py)）

```python
app.add_middleware(CORSMiddleware, allow_origins=["*"], allow_credentials=True,
                   allow_methods=["*"], allow_headers=["*"])
app.add_middleware(LoggingMiddleware)   # 自定义：记录方法/路径/状态/耗时/IP
app.add_middleware(AuthMiddleware)      # 自定义：JWT 校验
app.include_router(gateway_router, prefix="/api")
```

### 5.1 LoggingMiddleware

```
{request.method} {request.url.path} {response.status_code} {process_time:.4f}s {request.client.host}
```

### 5.2 AuthMiddleware

公共路径白名单（无需 JWT）：

```python
public_paths = [
    "/api/docs",
    "/api/redoc",
    "/api/openapi.json",
    "/api/auth/login",
]
# 以及任何以 /api/auth/ 开头的路径
```

校验逻辑：

```python
authorization = request.headers.get("Authorization")
token = authorization.replace("Bearer ", "")
payload = verify_jwt_token(token)
request.state.user = payload      # 透传给下游
```

> 当前实现**未将解析后的用户信息回写到下游请求头**。下游服务自行使用 `oauth2_scheme` 重新解析 Token。如果需要去除下游解析负担，可以在转发前注入 `X-User-Id` 等自定义头。

## 七、限流（[`gateway/core/limiter.py`](../gateway/core/limiter.py)）

```python
limiter = Limiter(
    key_func=get_remote_address,
    storage_uri=f"redis://{redis_host}:{redis_port}/{redis_db}",
)
```

- 全局策略：`100 次 / 60 秒 / 单个客户端 IP`（可在 `.env` 中调整）
- 命中限流：HTTP 429，返回中文提示：`请求过于频繁，请稍后再试。限制：N次/M`

如需粒度控制，对单个接口加 `@limiter.limit("10/minute")` 即可。

## 九、扩展指南

### 9.1 新增下游服务路由

1. 在 `gateway/core/env.py` 增加 `xxx_service_url: str = "http://127.0.0.1:80xx"`；
2. 在 `gateway/router/gateway_router.py` 的 `service_routes` 加入前缀；
3. 重启 gateway 即可生效（开发模式开启 `reload=True` 自动重启）。

### 9.2 自定义路由级权限

- 简单做法：在 `AuthMiddleware` 中根据 `path` + `request.state.user["roles"]` 判断；
- 进阶做法：在网关引入 `casbin` / RBAC 决策引擎；
- 业务级（数据权限）建议放在下游 service 层，结合菜单 / 部门进行过滤。

### 9.3 链路追踪

当前已在 system 内部使用自研 `TraceASGIMiddleware`（[`system/middlewares/trace_middleware`](../system/middlewares/trace_middleware/)）注入 trace_id。可在网关也启用同一中间件，并在转发时把 `X-Trace-Id` 透传给下游统一日志检索。

### 9.4 灰度/A-B

`get_target_service` 内部可改造为按请求头/比例选择不同的下游 URL，实现金丝雀发布。
