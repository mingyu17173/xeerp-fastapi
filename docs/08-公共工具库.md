## 二、响应工具 `ResponseUtil`

所有接口**必须**通过 `ResponseUtil` 返回响应，确保统一格式。

### 2.1 方法列表

| 方法 | code | 含义 |
| ---- | ---- | ---- |
| `success(msg, data, rows, ...)` | 200 | 成功 |
| `failure(msg, data, ...)` | -1（`WARN`） | 业务失败（可预期） |
| `unauthorized(msg, ...)` | 401 | 未登录/Token 过期 |
| `forbidden(msg, ...)` | 403 | 无权限 |
| `error(msg, ...)` | 500 | 系统异常 |
| `streaming(data, ...)` | 200 | 流式响应（下载/导出） |

### 2.2 响应结构

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": { ... },
  "rows": [...],
  "success": true,
  "time": "2026-05-15T09:00:00"
}
```

分页场景额外字段：`total`, `pageNum`, `pageSize`, `hasNext`。

## 三、分页工具 `PageUtil`

```python
# 方式一：内存分页
result = PageUtil.get_page_obj(data_list, page_num=1, page_size=10)

# 方式二：SQL 分页（推荐，性能最优）
result = await PageUtil.paginate(db, query, page_num=1, page_size=10, is_page=True)

# 方式三：已有 total 的情况
result = await PageUtil.paginate_to(db, query, total=100, page_num=1, page_size=10, is_page=True)
```

返回 `PageResponseModel`（自动驼峰序列化）：

```json
{
  "rows": [...],
  "pageNum": 1,
  "pageSize": 10,
  "total": 100,
  "hasNext": true
}
```

## 四、日志工具 `log_util`

```python
from utils.log_util import setup_logger

logger = setup_logger("system")   # 服务启动时调用
logger.info("Hello")
```

### 特性

| 特性 | 实现 |
| ---- | ---- |
| 输出 | 同时到控制台 + 文件 |
| 文件路径 | `项目根/logs/{service_name}.log` |
| 轮转策略 | 每天午夜（`TimedRotatingFileHandler when='midnight'`） |
| 保留天数 | 30 天 |
| 归档 | 轮转时自动 zip 压缩旧日志并删除原文 |
| 格式 | `%(asctime)s | %(levelname)s | %(module)s:%(funcName)s:%(lineno)d - %(message)s` |

## 六、文件上传

`UploadSettings` 定义：
- `UPLOAD_PREFIX = '/profile'`
- `UPLOAD_PATH = 'static'`
- `DEFAULT_ALLOWED_EXTENSION = ['jpg', 'png', 'doc', 'xls', 'pdf', ...]`

上传接口使用 `upload_util.py` 处理存储，返回 `{前缀}/{filename}` 作为访问 URL。

## 八、使用方式

各服务 `run.py` 启动时自动注入项目根到 `sys.path`：

```python
project_root = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
sys.path.insert(0, project_root)
```

然后任何地方 `from utils.xxx import ...` 即可。

## 九、扩展建议

1. 将 `utils/` 独立为 pip 包（`xeerp-utils`），便于版本管理与多仓库复用。
